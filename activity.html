My Coursework & Activities

Practical exercises, ethical dilemmas, and technical projects undertaken during my BSIT journey.

Activity 01 • Ethics & Analysis

IT Code of Ethics Case Study

Examined scenarios regarding intellectual property rights, data breaches, and developer liability. Evaluated ethical responses according to industry standards like ACM and IEEE codes of ethics.

Key Learning: Ethics must precede execution; just because a feature is technically viable does not mean it is right to deploy.
Activity 02 • Web Engineering

Responsive & Accessible Web Design

Constructed semantic web pages adhering to modern web standards, WCAG contrast ratios, and fluid responsive layouts across desktop and mobile devices.

Key Learning: Designing accessible interfaces reflects the "Respect" pillar by ensuring technology is usable by all individuals.
Activity 03 • Collaboration

Team Dynamics & Code Review

Participated in group software exercises involving task delegation, mutual code reviews, and structured constructive critique under project deadlines.

Key Learning: Practicing reliability and clear communication builds resilient team rapport and superior product quality.
Activity 04 • Continuous Growth

Emerging Tech & Cybersecurity Awareness

Researched current trends in Artificial Intelligence safety, secure authentication practices, and defensive software design to prevent common vulnerability exploits.

Key Learning: Embodying "Readiness to Learn" keeps our skills relevant and guards against emerging security pitfalls.
